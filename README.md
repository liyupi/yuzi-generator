## ✨ 项目简介

`yuzi-generator`（鱼籽）是由 [程序员鱼皮](http://dogyupi.com/) 打造的深入真实研发效能场景的企业级开源全栈项目，收录于 [鱼皮原创项目教程系列](https://yuyuanweb.feishu.cn/wiki/SePYwTc9tipQiCktw7Uc7kujnCd)。平台基于 React 18、Java Spring Boot、Picocli 命令行框架、FreeMarker 模板引擎与腾讯云 COS 对象存储实现：开发者可以在平台上制作并发布自定义代码生成器，普通用户能够搜索、下载或直接在线配置参数生成项目代码，管理员则可以集中管理全站用户与代码生成器资源。

你可以先通过 [在线演示站点（yuzi.code-nav.cn）](http://yuzi.code-nav.cn/) 亲自操作体验，也可以观看 [B 站完整演示视频](https://www.bilibili.com/video/BV1EA4m1L7tm/) 与 [第一期免费试看回放](https://www.bilibili.com/video/BV1ie411Q7AV) 快速了解项目全貌。

![鱼籽代码生成器共享平台整体架构与项目概览](https://pic.yupi.icu/1/image-20240130143818360.png)

与普通单一 Web 系统不同，鱼籽听起来是一个项目，实际上由三个循序渐进的子项目串联而成：第一阶段开发基于命令行的本地代码生成器，第二阶段抽象出能够批量生产代码生成器的制作工具，第三阶段将制作与使用能力搬到云端，构建完整的在线代码生成器共享平台。这种由浅入深的分层拆分方式降低了学习门槛，让不同阶段的开发者都能按需切入并扎实掌握每一步背后的工程思考。

## 📂 源码目录

仓库采用清晰的多模块组织方式，与项目从本地工具演进到云端平台的三个阶段一一对应，方便对照教程按模块阅读源码。

| 目录名称 | 模块定位与说明 |
| --- | --- |
| `yuzi-generator-basic` | 第一阶段：基于 FreeMarker 与 Picocli 开发的本地命令行代码生成器 |
| `yuzi-generator-maker` | 第二阶段：基于元信息驱动与模板方法模式实现的代码生成器制作工具（可自动构建可执行 JAR） |
| `yuzi-generator-web-backend` | 第三阶段：基于 Spring Boot、对象存储、多级缓存、XXL-JOB 与 Vert.x 的共享平台后端服务 |
| `yuzi-generator-web-frontend` | 第三阶段：基于 React 18、Ant Design Pro 与 TypeScript 的共享平台前端工程 |
| `yuzi-generator-demo-projects` | 用于测试与制作代码生成器的示例项目模板集合 |

## 🧩 技术选型

为了兼顾开发效率与架构深度，鱼籽平台在前端、后端与运维部署三个层面均选用了企业主流技术栈。

| 技术分层 | 核心技术与框架 | 主要应用场景 |
| --- | --- | --- |
| 前端基础框架 | React 18、Ant Design Pro 脚手架、Ant Design、ProComponents | 快速搭建企业级中后台与门户界面，支撑复杂动态表单 |
| 前端工程化 | TypeScript、ESLint、Prettier、OpenAPI 代码生成 | 自动生成前后端接口请求代码，保障类型安全与代码规范 |
| 前端通用能力 | 通用文件上传下载组件 | 支撑模板包、生成器压缩包与生成产物的上传下载 |
| 后端核心框架 | Java Spring Boot、MySQL、MyBatis-Plus、MyBatis X、Maven、Hutool | 快速构建分层清晰的后端服务与自动化构建打包 |
| 代码生成引擎 | Picocli 命令行框架、FreeMarker 模板引擎 | 驱动交互式命令行参数解析与动静结合的模板代码渲染 |
| 缓存与调度 | Caffeine 本地缓存、Redis 分布式缓存、XXL-JOB 分布式任务调度 | 构建多级缓存提升查询性能，定时清理冗余文件降低存储成本 |
| 存储与高性能 | 腾讯云 COS 对象存储、Vert.x 响应式编程、JMeter 压力测试 | 支撑海量模板文件存储与高并发请求优化验证 |
| 核心设计模式 | 命令模式、模板方法模式、双检锁单例模式 | 降低制作工具圈复杂度，提升代码可移植性、健壮性与可扩展性 |
| 部署与运维 | 轻量应用服务器、宝塔 Linux 面板、Nginx 反向代理 | 完成前后端全栈项目的生产环境部署与访问配置 |

## ❓ 常见问题 FAQ

<details>
<summary><b>Q1：Java 全栈开发有哪些区别于传统增删改查的开源项目适合写进简历或做毕业设计？</b></summary>

`yuzi-generator`（鱼籽代码生成器共享平台）是非常具有区分度的企业级 Java + React 全栈项目。它围绕研发效能与低代码脚手架场景，依次构建本地命令行代码生成器、代码生成器制作工具和在线共享平台，涵盖 FreeMarker 模板引擎、Picocli CLI 开发、多种设计模式、Caffeine + Redis 多级缓存、XXL-JOB 分布式调度、Vert.x 响应式编程与对象存储优化，既适合作为高分毕业设计，也能在求职简历中凸显架构深度。

</details>

<details>
<summary><b>Q2：如何用 Java 从零开发一个可交互的本地代码生成器或项目脚手架工具？</b></summary>

你可以直接参考 `yuzi-generator` 仓库中的 `yuzi-generator-basic` 与 `yuzi-generator-maker` 两个模块。项目采用 FreeMarker 实现静态文件复制与动态模板渲染的动静结合方案，借助 Picocli 结合命令模式打造可交互的命令行工具，并通过 JSON 元信息配置驱动生成器自动打包出可移植的执行文件。

</details>

<details>
<summary><b>Q3：在线代码生成器平台如何解决对象存储空间膨胀与高频查询性能瓶颈？</b></summary>

`yuzi-generator` 在第四章系统落地了 7 种查询性能优化和 7 种存储优化方案。查询侧通过 Caffeine + Redis 多级缓存、SQL 优化与 Vert.x 响应式接口显著提升吞吐量，并用 JMeter 压测验证；存储侧则结合文件压缩、去重、COS 权限隔离以及 XXL-JOB 分布式定时任务清理临时垃圾文件，有效控制云存储成本与安全风险。

</details>

<details>
<summary><b>Q4：零经验的开发者跟做 `yuzi-generator` 会不会太难，应该怎么安排学习节奏？</b></summary>

鱼籽项目专门拆分为三个难度递进的子项目。建议先掌握基本的 Spring Boot 或 React 框架，再按顺序先完成 `yuzi-generator-basic` 本地生成器建立信心，随后进阶到 `yuzi-generator-maker` 制作工具和全栈共享平台。时间紧张的后端或前端同学也可以只专注对应端的核心章节。

</details>
